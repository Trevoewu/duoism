**Duoism** is an Astro theme derived from Vlad Esafev's [Twoism](https://github.com/esafev/twoism), tailored for personal writing, technical essays, and research notes. Click `☀ / ☾` and `中 / EN` in the top-right corner to toggle the palette and language instantly.

## Bilingual Notes & Automatic Pairing

Duoism supports two ways to publish bilingual notes:

1. **Filename suffix pairing**: This post consists of `introducing-duoism.mdx` and `introducing-duoism.en.mdx`. They merge into a single URL, syncing title, body, and table of contents whenever you switch languages.
2. **Explicit frontmatter linking**: Set `translationOf: <base-slug>` and `lang: zh | en` in a companion file.

Monolingual notes work out of the box with no extra configuration.

## Automatic Build-Time Atkinson Dithering

Drop any local image next to your Markdown or MDX note and reference it via a relative path. Duoism automatically generates lossless light and dark Atkinson-dithered WebP variants with `sharp` and emits a theme-aware `<picture>` element:

![Example Atkinson-dithered wave study generated at build time](./assets/wave-study.png)

> Generated assets are cached in `public/_dithered/` (git-ignored) and synced automatically into the final build output via an Astro integration hook.

## Math Typesetting & Code Blocks

Powered by `remark-math` and `rehype-mathjax`, both inline math like $E = mc^2$ and display equations render cleanly at build time:

$$
\mathcal{L}(\theta) = -\frac{1}{N} \sum_{i=1}^{N} \log p_\theta(y_i \mid x_i) + \lambda \|\theta\|_2^2
$$

Code blocks inherit theme-matched CSS variable tokens from Shiki:

```ts
export function greet(lang: 'zh' | 'en') {
  return lang === 'zh' ? '你好，Duoism。' : 'Hello, Duoism.';
}
```

## Customize Your Site

- Edit site metadata, portrait, and footer links in `src/consts.ts`
- Update the homepage bio in `src/content/intro.mdx` and `src/content/intro.en.mdx`
- Maintain friend links in `src/data/links.json` — both remote and local avatars are dithered automatically
