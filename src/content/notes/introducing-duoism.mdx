**Duoism** 基于 Vlad Esafev 的 [Twoism](https://github.com/esafev/twoism) 扩展而来，面向个人写作、技术随笔与研究笔记。点击右上角的 `☀ / ☾` 与 `中 / EN`，你可以即时体验整站的主题与语言切换。

## 双语写作与自动配对

Duoism 支持两种双语文章组织方式：

1. **文件名后缀自动配对**：例如本文由 `introducing-duoism.mdx` 与 `introducing-duoism.en.mdx` 组成，系统会自动聚合为同一篇笔记，并在切换语言时无缝同步标题、正文与侧边目录。
2. **显式指定关系**：在译文 frontmatter 中填写 `translationOf: <主文章 slug>` 和 `lang: zh | en`。

单语文章同样可以正常发布，无需额外配置。

## 构建期自动 Atkinson 抖动图像

你只需要像平常一样在 Markdown 或 MDX 中插入相对路径图片，Duoism 会在开发与构建阶段自动调用 `sharp` 生成浅色与深色两套 Atkinson 抖动 WebP 图像，并输出响应式 `<picture>` 标签：

![构建期自动生成的 Atkinson 抖动波形示例](./assets/wave-study.png)

> 缓存结果默认写入被 `.gitignore` 忽略的 `public/_dithered/` 目录，并在 `astro:build:done` 阶段自动同步到构建产物。

## 数学排版与代码块

内置 `remark-math` 与 `rehype-mathjax`，支持行内公式 $E = mc^2$ 以及块级公式：

$$
\mathcal{L}(\theta) = -\frac{1}{N} \sum_{i=1}^{N} \log p_\theta(y_i \mid x_i) + \lambda \|\theta\|_2^2
$$

代码块使用与主题色协调的 CSS Variables Shiki 配色：

```ts
export function greet(lang: 'zh' | 'en') {
  return lang === 'zh' ? '你好，Duoism。' : 'Hello, Duoism.';
}
```

## 自定义你的站点

- 修改 `src/consts.ts` 中的站点名称、描述、链接与头像设置
- 编辑 `src/content/intro.mdx` 与 `src/content/intro.en.mdx` 自定义首页简介
- 在 `src/data/links.json` 中维护你的友链，远程与本地头像都会自动抖动化
